# Connectify - Full Stack Social Media Platform

CodeAlpha Full Stack Development Internship
Task 2 - Social Media Platform

*Currently in Phase 1: Project Setup*

## Features to be implemented
- User Authentication (JWT)
- User Profiles
- Post creation and management
- Likes & Comments
- Follow/Unfollow system
- Home Feed
- Search and Explore
- Notifications

## Tech Stack
**Frontend:** React, Vite, Tailwind CSS, React Router, Axios, Context API, Lucide React
**Backend:** Node.js, Express.js, MongoDB Atlas, Mongoose, JWT, bcryptjs
